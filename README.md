# Twisungane Platform

Full-stack SACCO (savings & credit cooperative) management system for Twisungane, Rwanda.

- **Backend:** Spring Boot 3 / Java 21 / PostgreSQL (`backend/`)
- **Frontend:** React 19 / Vite (`frontend/`)
- **Languages:** English, French, Kinyarwanda

See [DEPLOYMENT.md](DEPLOYMENT.md) for setup and deployment.
